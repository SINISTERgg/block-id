# Design System: BlockID
**Project Type:** Web Application (Desktop-first, responsive)
**Design Philosophy:** Clean, confident, human-crafted — avoiding generic AI aesthetics

## 1. Visual Theme & Atmosphere

BlockID embraces a **confident, editorial aesthetic** that feels designed by humans, not generated by AI:
- **Clean & Solid**: No excessive glassmorphism or gradients — just solid, confident cards and elements
- **Bold Typography**: Strong typographic hierarchy with Space Grotesk for display text
- **Purposeful Whitespace**: Intentional spacing that creates breathing room
- **Subtle Patterns**: Dotted backgrounds as texture, not overwhelming gradients

### Mood Descriptors
- Confident, Professional, Trustworthy
- Human-crafted feel
- Clean without being sterile
- Modern without being trendy

## 3. Typography Rules

### Font Families
- **Display Font**: `Space Grotesk` — Bold, geometric, distinctive
- **Body Font**: `Inter` — Clean, readable, professional

### Scale
| Element | Weight | Size |
|---------|--------|------|
| Display | 700 | clamp(2.5rem, 5vw, 4rem) |
| Headline | 600 | clamp(1.5rem, 3vw, 2.25rem) |
| Title | 600 | 1.125rem |
| Body | 400 | 14-16px |
| Caption | 400 | 12px |

## 4. Component Stylings

### Cards (Solid)
- **Background**: `hsl(var(--card))` — Solid white/gray, no glassmorphism
- **Border**: 1px solid `hsl(var(--border))`
- **Shadow**: Subtle `0 1px 3px` on light, deeper on dark
- **Hover**: Lift with enhanced shadow
- **Radius**: `0.5rem` (8px)

### Buttons
| Type | Style |
|------|-------|
| Primary | Solid terracotta background, white text |
| Secondary | Solid background with border |
| Ghost | Transparent, hover shows background |
| Outline | Border only, transparent background |

### Inputs
- **Border**: 1px solid border color
- **Focus**: Primary color ring with 10% opacity
- **Radius**: `0.5rem`

### Badges
- **Style**: Solid background with rounded-full pill shape
- **Uppercase**: Small caps for labels

## 5. Layout Principles

### Spacing System
- Base unit: 4px
- Common spacings: 4, 8, 12, 16, 24, 32, 48px
- Section padding: 48-64px vertical

### Grid System
- 3-column for portal cards
- Responsive breakpoints: sm(640px), md(768px), lg(1024px)

### Visual Effects
- **Dot Pattern**: `radial-gradient` dots for subtle texture
- **Line Accents**: Small underline strips on headings
- **Stat Numbers**: Large, tabular-nums for dashboard metrics

## 6. Animation Guidelines

### Transitions
- Duration: 200-300ms
- Easing: `ease` — Simple and confident

### Motion Types
- **Fade In Up**: For card entrances
- **Hover Lift**: For interactive elements
- **Subtle**: No excessive bouncing or spinning

## 7. Accessibility

- Minimum contrast ratio: 4.5:1
- Focus states with visible rings
- Semantic HTML elements
- Reduced motion support
